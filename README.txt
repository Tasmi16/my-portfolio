# Beginner Portfolio Website

## Files
- `index.html` - website content
- `css/style.css` - design and responsive layout
- `js/script.js` - theme toggle, mobile menu, changing role text and current year

## How to run
1. Extract the ZIP file.
2. Open the `portfolio_website` folder in VS Code.
3. Open `index.html` in your browser (or use the Live Server extension).

## Edit before publishing
1. Replace `Your Name` with your name in `index.html`.
2. Change `YN` in the profile circle to your initials.
3. Replace `your-email@example.com` with your email.
4. Add your real GitHub and LinkedIn profile links.
5. Edit the About, Skills and Projects sections to match your own work.
6. To use your photo, add `profile.jpg` in the main folder and replace the profile-placeholder div in `index.html` with:
   `<img class="profile-photo" src="profile.jpg" alt="My profile photo">`
   Then add this CSS:
   `.profile-photo { width:100%; height:100%; object-fit:cover; border-radius:50%; }`

This project uses beginner-level HTML, CSS and a small amount of JavaScript. The theme preference is saved in the browser.
